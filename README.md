🛒 SpaceMark – Sistema de información para supermercado

📌 Descripción

SpaceMark es un sistema de información para la gestión de un supermercado, desarrollado como proyecto de software utilizando PHP y MySQL.

El proyecto permite administrar diferentes procesos relacionados con los productos, usuarios, inventario y compras.

🛠️ Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

⚙️ Funcionalidades

- Gestión de usuarios.
- Administración de productos.
- Gestión de inventario.
- Carrito de compras.
- Proceso de compras.
- Almacenamiento de información en base de datos.

🗄️ Base de datos

El proyecto utiliza MySQL para almacenar y gestionar la información del sistema.

💻 Instalación

1. Descargar o clonar el repositorio.
2. Instalar un servidor local como XAMPP.
3. Iniciar Apache y MySQL.
4. Importar el archivo SQL en phpMyAdmin.
5. Configurar la conexión a la base de datos en "conexion.php".
6. Abrir el proyecto desde el navegador mediante localhost.
